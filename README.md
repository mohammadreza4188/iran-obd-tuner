# iran-obd-tuner

نرم‌افزار یکپارچه **تشخیص و تیونینگ خودرو** با پایتون مخصوص بازار ایران

## هدف پروژه

ساخت یک ابزار یکپارچه که بتواند همزمان:

- عیب‌یابی و خواندن/پاک کردن کدهای خطا (DTC) و مشاهده Live Data از طریق OBD-II
- تیونینگ و ریمپ ECU (فعلاً فقط در حالت Bench)

را پوشش دهد.

## اصول طراحی (نسخه فعلی)

1. **اولویت‌بندی خودروها**: تمرکز اولیه روی خانواده‌های پرتیراژ (ایران‌خودرو، سایپا و یک برند چینی)
2. **جداسازی کامل Diagnostics و Tuning**: تیونینگ در نسخه‌های اولیه فقط به صورت Bench
3. **دیتابیس دانش**: ساخت دیتابیس نقشه‌ها و تعاریف ECU مخصوص خودروهای ایرانی
4. **ایمنی بالا**: کاهش ریسک آجر شدن ECU با پشتیبان‌گیری اجباری و تأیید چندمرحله‌ای

## ساختار پروژه

- docs/                  مستندات و گزارش ایده
- src/diagnostics/       بخش تشخیص (OBD-II)
- src/tuning/            بخش تیونینگ (Bench)
- src/hardware/          ارتباط با سخت‌افزار
- src/database/          دیتابیس دانش
- src/ui/                رابط کاربری (PySide6)
- tests/
- scripts/
- requirements.txt
- README.md

## وضعیت فعلی

- فاز ۰: راه‌اندازی ریپازیتوری و ساختار اولیه
- فاز ۱: داشبورد تشخیصی با python-OBD + PySide6
